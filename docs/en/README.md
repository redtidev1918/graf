# Graf Documentation

**Language / 语言:** [中文](/) · English

> Graf is a minimal, **self-hosted Markdown publishing platform** that is
> **compatible with Telegra.ph (the Telegraph API)**. The whole service runs on
> **Cloudflare Workers + D1**: publishing gives you a short-link page, with optional
> paragraph-level comments.
